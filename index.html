Brancher le projecteur

Le site lit ses données sur TMDB. Il faut une clé API gratuite :

  1. Crée un compte sur themoviedb.org.
  2. Va dans Paramètres → API et demande une clé (usage personnel).
  3. Colle la « Clé de l'API » (v3) ou le « Jeton d'accès en lecture » ci-dessous.

La clé reste dans ce navigateur.

Genres

Disponible en streaming (France)

Pour « Aujourd'hui » et « Cette semaine », TMDB ne filtre pas côté serveur : genres, années, langue et note sont filtrés sur la liste des tendances. Le pays, la durée, le public et les plateformes s'appliquent à partir de « Ce mois-ci ».

Ce site utilise l'API TMDB mais n'est ni approuvé ni certifié par TMDB. Disponibilités streaming fournies par JustWatch.
